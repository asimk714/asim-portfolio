Try the Taskflow concept

This interactive demonstrates the Taskflow concept: arrange apps into a work context, save it as a named workspace, and restore it later. The prototype shows the core save/restore flow — the interaction model that would make workspace continuity feel native. The data is illustrative. No real OS, no real apps, no real user data.

Prototype functionality is demonstrated here. This is not a Microsoft product.

How to try it

  1. Click an app in the taskbar to open it on the desktop
  2. Click a window's close button to close it
  3. Arrange the open apps to represent a work context
  4. Enter a name and click "Save Workspace"
  5. Open more apps, then click "Restore" to return to a saved workspace
