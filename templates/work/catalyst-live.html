Design decisions

Shortcuts shown in UI

Keyboard shortcuts are visible in the interface, not hidden behind a menu. New users can discover them without memorizing a command palette.

Filter chips always visible

Status filters are always visible in the top bar, not buried. The paradigm is discoverable by scanning, not by remembering.

Progressive onboarding

The interface starts with the list and the shortcuts visible. Advanced features (command palette, project management) are not required to experience the core paradigm.

These are design decisions, not validated results. No user research backs them.
