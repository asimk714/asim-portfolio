The Funnel

D1 Retention Funnel

Measurement Model

The funnel tracks a new user from first session through D1 return. Each stage is instrumented as an analytics event. Hover or tap a stage to see what it measures.

1 first_session_started

New user starts first session

Recorded when onboarding begins. Entry point of the funnel.

2 onboarding_completed

User completes 3-step onboarding

Role, goal, experience selected. UserPreference saved.

3 plan_viewed

5-day curriculum plan displayed

Personalized learning path. Day 1 lesson highlighted.

4 lesson_started

User opens Day 1 lesson

Lesson reader loads. Progress tracking begins.

5 lesson_completed

Knowledge check passed, lesson done

LessonProgress stores startedAt, quizScore, completedAt.

6 reminder_enabled

User opts into daily reminder

Time (HH:mm) + timezone saved. No real notification sent.

7 D1_returned

User returns next calendar day

Qualifying return event on calendar day D0+1 — the North Star metric.

Calculator

D1 Retention Calculator

Pure TypeScript

The calculator computes D1 retention from a list of analytics events, using the user's configured timezone (or UTC fallback). It excludes demo return previews and enforces the cohort completeness rule: a cohort on day D is incomplete until day D+2 has closed.

A/B Experiment

Control vs Treatment

Design Only

Control (A)

Generic onboarding

  • Static unpersonalized lesson list
  • No 5-day goal syllabus
  • No tomorrow's lesson preview
  • No reminder preference
  • ~50% allocation

Treatment (B)

Personalized retention loop

  • Role/goal/experience selection
  • Tailored 5-day curriculum
  • Tomorrow's lesson preview on completion
  • Optional daily reminder (HH:mm + timezone)
  • Returning-user /home dashboard
  • ~50% allocation

Key design parameters

Primary metric: D1 retention rate (calendar-day, timezone-aware)
Baseline: 16% (assignment-provided context, not author-measured)
Target: 22% (+6pp, +37.5% relative)
Sample size: ~650–700 per variant (~1,300–1,400 total)
Duration: 2 weeks + 2-day cooldown
Decision rule: p < 0.05, guardrails within tolerance

Experiment design is complete. The experiment has not been run — no real users, no real D1 measurement.
