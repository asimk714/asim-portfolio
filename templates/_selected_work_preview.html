Problem Statement

Micro-learning platforms suffer catastrophic day-1 drop-off. The assignment baseline is 16% D1 retention, with a hypothetical target of 22%. The product failure isn't lack of content; it's absent habit loops and friction at the return threshold.

JTBD & Behavioral Hypotheses

Mapped 4 distinct Jobs-to-be-Done and derived 7 intervention hypotheses. Isolated H4 (return-intent commitment at the end of Session 1) as the highest-impact, lowest-effort experiment candidate.

Measurement Model & A/B Design

Architected full experiment specification: primary metric (D1 return rate), guardrail metric (session completion quality), minimum detectable effect (MDE) statistical power analysis, and explicit decision rules for shipping.

Honest Disclosures & Reality

Full honesty: 29 of 50 automated tests pass locally; 21 fail without live PostgreSQL credentials. The 16% baseline is context, not measured user data. No live experiment has been run on production traffic.

Windows 11 Taskflow — Shell Multitasking Teardown

Solo Product Teardown · 20-Phase Analysis, UX Prototyping, PRD

Problem: Multitasking across 5+ active windows creates repetitive manual re-tiling, lost context on reboot, and cognitive fatigue.

Key Decision: Benchmarked macOS Stage Manager and ChromeOS Virtual Desks; formulated native shell-level Taskflow with HEART framework metrics.

Problem Statement

Windows 11 users with 5+ open windows face constant context-switching overhead, manual window repositioning, and complete loss of working state upon system restart. Existing Snap Layouts solve layout, not intent.

Competitive Benchmarking

Analyzed macOS Stage Manager, macOS Spaces, ChromeOS Virtual Desks, and Linux workspace managers. Identified the critical gap: desktop operating systems organize windows by application, not by task.

Feature Formulation — Taskflow

Architected 'Windows Taskflow' — an intelligent task-clustering shell flyout that groups apps by active project, preserves state across reboots, and offers quick context restoration from the taskbar.

HEART Success Metrics

Defined structured measurement framework: Happiness (CSAT on multitasking), Engagement (tasks created per week), Adoption (% of users grouping 2+ windows), Retention (D30 task usage), Task Success (time to switch contexts).
