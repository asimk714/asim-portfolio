Problem Statement

Modern OS shells still behave like basic app launchers — every reboot, reconnect, or context switch forces knowledge workers to manually reconstruct multi-app arrangements, taxing focus dozens of times per week.

Competitive Benchmarking

Benchmarked against macOS Stage Manager and ChromeOS Tab Groups — both isolate windows or tabs. Taskflow differentiates by packaging full cross-app state (apps + tabs + documents) with shareable cloud links.

Prioritization Framework

Evaluated feature candidates using RICE and MoSCoW. Native local state restore under 3.5 seconds scored highest on Reach and Impact, establishing the non-negotiable performance standard.

Desk research, direct teardown of Windows 11 taskbar/shell interactions, and synthesis of public developer forums — noted plainly as structured product teardown rather than primary user interviews.

Solo Product Teardown · UX Diagnostics, Redesign, Interactive Prototype

A checkout teardown and redesign for India's highest-stakes 75-minute booking window — Tatkal ticketing — where asynchronous ad scripts and sudden layout shifts quietly cause transaction drop-offs for millions of users.

Problem Statement

During the 10:00–11:15 AM Tatkal window, IRCTC's checkout asynchronously loads heavy ad scripts mid-transaction, causing sudden Cumulative Layout Shifts (CLS), mis-taps, payment gateway timeouts, and lost bookings.

Funnel Diagnostics

Isolated three severe failure modes: layout-shift-driven invalid taps on form buttons, unthrottled non-essential scripts competing for client thread bandwidth, and silent session expiry under peak concurrency.

Product Strategy

Protect the critical booking path: freeze non-essential third-party advertising scripts during the 75-minute window and introduce an explicit client-side virtual waiting queue rather than silent failure.

Prioritization & Implementation

MoSCoW triage: P0 — Passenger Autofill and Peak-Hour Ad-Free Script Freeze (removes the primary leak points); P1 — Client-Side Virtual Queue (stabilizes user perception under server backpressure).

KPIs & Business Impact

Checkout Completion (Peak Window)Target: ↑
Checkout LatencyPriority: High
Layout-Shift IncidentsAddressed by P0
Key Takeaway: In high-stakes, time-boxed transactions, protecting the critical path is worth far more than short-term ad revenue. A transparent waiting state beats an unexplained timeout every time.
