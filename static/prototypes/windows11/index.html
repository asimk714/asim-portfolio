PRD-01: Windows Taskflow Workspaces

StatusIn Progress
PM OwnerAsim Kumar
Engineering LeadAlex Chen

1. Executive Overview

Modern operating systems behave as application launchers. Taskflow pivots the shell to manage user contexts, saving all related files, folders, and web tabs as a named project workspace.

2. Core Requirements

  • NPU local state coordination must execute in < 3.5 seconds.
  • Support OneDrive synchronization configuration parameters.
  • Generate viral collaboration links for simple coworker handoff setups.
