PM Assignment Context

The Concurrency vs. UX Challenge

IRCTC experiences massive database loads, specifically during peak Tatkal booking windows (10:00 AM & 11:00 AM). In the legacy application, the user experience is heavily degraded by programmatic banner advertisements that load asynchronously, causing sudden page shifts (Layout Shifts) and session drops.

Key Funnel Diagnostics Comparison

77.4% Leaky

Frequent time-out errors, layout shifts leading to invalid taps, and session expiry causes user drop-off.

Core Strategic Initiatives

P0/P1 Features Implemented in Redesign

P0

Smart Passenger Autofill

Suggests and auto-populates frequent traveler profiles dynamically based on historical bookings. Removes the need to manually type fields during high-stakes Tatkal windows.

P0

Peak-Hour Ad-Free Script Freeze

Automatically freezes non-essential Google AdMob and tracking scripts between 10:00–11:15 AM. Eliminates visual shifts and layout displacement.

P1

Client-Side Virtual Waiting Queue

Instead of crashing or dropping connections, user requests are routed to a client-side queue. Displays transparent live progress status to lower booking anxiety.
